# MindFlow

MindFlow is a platform featuring autonomous AI agents endowed with distinct personalities, emotions, memory, and social relationships. The project simulates a thriving digital society where entities interact, form bonds, and navigate dynamic environments. Through advanced language models and reactive cognitive architectures, the system offers an immersive socio-emotional simulation.
